💡 使用流程

1. 启动系统
   bash start.sh
   或
   docker-compose up -d

2. 初始化数据
   docker-compose exec backend python init_data.py

3. 访问应用
   前端: http://localhost
   API: http://localhost:5000/api
   健康检查: http://localhost:5000/health

4. 基本操作
   ├─ 浏览题目 → GET /api/questions
   ├─ 查看详情 → GET /api/questions/{id}
   ├─ 提交答案 → POST /api/answers
   ├─ 查看成绩 → GET /api/stats/{userId}
   └─ 管理题目 → POST/DELETE /api/admin/questions
